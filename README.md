# School Management System
A SQL Server based database management system for managing school records, attendance, exams, fees, timetables, teachers, students, and guardians.

## Features
- Student and Guardian Management
- Teacher and Subject Management
- Class Management
- Attendance Tracking
- Exam and Result Management
- Fee and Payment Tracking
- Timetable Scheduling
- Events and Announcements
- Academic Year Management

## Technologies Used
- SQL Server
- T-SQL
- SQL Server Management Studio
- Visual Paradigm

## Database Design
The database includes normalized tables such as Student, Guardian, Teacher, Class, Subject, Attendance, Exam, Exam_Result, Fee, Payment, TimeTable, Event, Announcement, and Academic_Year.

## How to Run
1. Open SQL Server Management Studio.
2. Open `school_management_system.sql`.
3. Execute the script.
4. The database and tables will be created.
5. Run the sample queries to test the system.
